# سَمْت — منصة ضبط السلوك والمواظبة (الإصدار 1.0.0)

وفق «قواعد السلوك والمواظبة لطلبة التعليم العام» — الإصدار الخامس 1447هـ.

## ما في هذا المجلد

| الملف | الغرض |
|---|---|
| `index.html` + `loader.js` | التطبيق (النواة الثابتة: قاعدة بيانات الجهاز، الاشتراك، التحديث) |
| `app.js` · `app.css` | الواجهة (هي ما يتغير مع ملفات التحديث) |
| `sign.html` | صفحة توقيع ولي الأمر (تفتح من رابط الواتساب) |
| `teacher.html` | صفحة رصد المعلم (تفتح من رابط الواتساب) |
| `template.xlsx` | قالب Excel للطلاب والمعلمين والإدارة |
| `firebase-rules.json` | قواعد صندوق البريد المؤقت |

## أين تُحفظ البيانات؟
- **كل بيانات الطلاب والمخالفات على جهاز المدرسة فقط** (IndexedDB)، ولا تُرفع لأي خادم.
- النموذج المرسل لولي الأمر محمول داخل الرابط نفسه.
- التوقيع وبلاغ المعلم يعودان **مشفرين** عبر صندوق بريد مؤقت (Firebase Realtime Database)، ويُحذفان فور استلامهما. مفتاح فك التشفير موجود في جهاز المدرسة فقط.
- **مجلد `sammt` على القرص (Chrome/Edge على الكمبيوتر):** يُختار مرة واحدة عند أول تشغيل، وتُحفظ فيه البيانات تلقائياً بعد كل تعديل مع نسخة يومية في `sammt/backups`. مسح المتصفح أو حذفه لا يمس البيانات؛ يُعاد ربط المجلد فتُستعاد البيانات والاشتراك.
- على الجوال: النسخ الاحتياطي اليدوي من الإعدادات ← النسخ الاحتياطي.

## النشر (مرة واحدة)
1. ارفع محتوى المجلد إلى استضافة ثابتة تعمل بـ https، مثل GitHub Pages.
2. أنشئ مشروع Firebase ثم Realtime Database، والصق محتوى `firebase-rules.json` في تبويب Rules ثم Publish.
3. في التطبيق، اذهب إلى الإعدادات ← الروابط والتوقيع، وأدخل:
   - عنوان الموقع
   - عنوان قاعدة البيانات
   - رقم واتساب المدرسة
   
   ثم اضغط «اختبار الاتصال».

## الاشتراك
- تعمل النسخة التجريبية 72 ساعة (ثلاثة أيام)، ثم يتوقف التطبيق. تبقى النسخة الاحتياطية وتثبيت التحديث متاحين حتى والتطبيق مقفل.
- يظهر للعميل **رقم جهاز**، فيُصدر له المطوّر كوداً من لوحة المطوّر (`samt-keygen.html`، ملف خاص) بتاريخ نهاية محدد. لا يعمل الكود إلا على ذلك الجهاز.

## التحديث
- يرسل المطوّر ملف `samt-x.y.z.slu`، ويختاره المستخدم من الإعدادات ← الاشتراك والتحديث.
- يتحقق التطبيق من توقيع الملف قبل تثبيته، ولا تتأثر البيانات بالتحديث.
- زر «الرجوع للإصدار المدمج» متاح عند أي مشكلة.
